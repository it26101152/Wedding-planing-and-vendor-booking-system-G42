# Formatting notes

- Java source files use separate lines for classes, methods and most statements; long
  method chains are wrapped.
- JSP pages use multiline HTML/CSS as in the supplied readable project.
- `pom.xml` is indented XML.
- Markdown files use headings and paragraphs.
- `.txt` files retain their original serialized records; do not split a single record
  over multiple lines, because file handling may depend on one record per line.

**Important:** This is a formatting-focused version of the supplied development
scaffold, not a verified production-ready implementation. Maven compile and web login
have not been tested here.
