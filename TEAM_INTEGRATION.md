# Team branch integration
Each member ZIP contains only its module (`src/main/java/com/weddingplanner/<module>`
and corresponding JSP) plus README. Merge modules into the integrated root project,
retaining shared common classes. Member 1 also owns AuthService/AuthController and auth
JSPs. The original repository supplied only the `main/` subtree; verify root pom and Git
branches before merging. Do not overwrite existing team work without review.
