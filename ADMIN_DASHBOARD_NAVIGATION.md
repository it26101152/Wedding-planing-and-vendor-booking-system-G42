# Admin Dashboard Navigation

Admin uses six clickable management boxes, matching the Customer Dashboard navigation style.

- Select a box to load that module in the dashboard iframe.
- Back and Next switch between modules without leaving `/admin`.
- The progress label shows Module 1 of 6 through Module 6 of 6.
- The existing module pages continue to provide their existing CRUD actions.
- No fake global OK/save button is added: each CRUD module saves its own records.
- Customer dashboard is unchanged.

Run the application and open `/admin` after logging in as ADMIN.
